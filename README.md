# BulkBackup

Copii de siguranță programate pentru bazele de date Saga.

BulkBackup rulează ca serviciu Windows pe calculatorul cu Saga. La ora aleasă copiază fiecare firmă și registrul
principal Saga, verifică fiecare copie și păstrează copiile după regula aleasă. Din fereastra BulkBackup vedeți starea,
istoricul copierilor și puteți restaura o copie.

**Descărcare și detalii:** https://bulkreporter.ro/tools/backup

## Versiuni

Fiecare versiune apare la [Releases](https://github.com/acs-soft/bulk-backup/releases), cu programul de instalare
`BulkBackup-Setup-<versiune>.exe`. Programul de instalare este semnat digital de ACS SOFT CONSULT SRL. Amprenta
SHA-256 a fiecărui fișier este trecută în descrierea versiunii.
